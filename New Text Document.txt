HTML(เฮด ที เอม แอล) = สร้าง “โครงสร้างหน้าเว็บ” สร้างหัวข้อ, รายชื่อร้าน, ปุ่มค้นหา

CSS(ซี เอส เอส) = ตกแต่งให้ “สวยและเป็นระเบียบ” สีพื้น, ตัวหนังสือ, กรอบการ์ดร้านหนังสือ

Python(ไพ ทอน) = ทำให้ “เว็บขยับได้ / โต้ตอบได้” ปุ่มค้นหา, ซ่อน/โชว์รายละเอียดร้าน, โหลดข้อมูลจาก Python

JavaScript(จาวาสคริป) = เป็น “สมองหลังบ้าน (Server)” รับคำค้นจาก JS → ส่งข้อมูลร้านที่ตรงกลับมา




ข้อมูล	ใช้ Fetch API (JavaScript) ส่งคำขอไปหา Flask หลังบ้าน 
Python (Flask) รับคำขอ, ประมวลผล, ส่งข้อมูลกลับ	
ใช้ HTTP Response (JSON) ส่งกลับไปให้ JS

มันคือการส่งข้อมูลระหว่าง Frontend ↔ Backend

GET	ขอข้อมูลจาก Server	เวลา JS ขอข้อมูลร้านจาก Flask
POST	ส่งข้อมูลไปเก็บที่ Server เวลา JS ส่งข้อมูลสมัครสมาชิก หรือเพิ่มร้านใหม่



Frontend (ฝั่งผู้ใช้) = HTML	สร้างโครงสร้างเว็บ มีหัวข้อ "ร้านหนังสือใกล้ฉัน", รายชื่อร้าน, ช่องค้นหา
CSS = ตกแต่งหน้าตาเว็บ	ทำให้หน้าดูสวย เช่น สีพื้นหลัง, เงาการ์ด, ปุ่มโค้ง
JavaScript = ทำให้เว็บโต้ตอบได้	เมื่อพิมพ์คำค้น → เรียกข้อมูลจาก Python แล้วแสดงผล
Backend (ฝั่งเซิร์ฟเวอร์) = Python (Flask) ประมวลผลหลังบ้านรับคำค้นจาก JS, ค้นข้อมูลร้านในฐานข้อมูล, ส่งผลกลับเป็น JSON
